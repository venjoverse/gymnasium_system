GYMNASIUM EVENT IN/OUT SYSTEM MANAGEMENT

The Gymnasium Event In/Out System Management is a web-based application designed to help schools organize gymnasium events and monitor student attendance. It provides a central place to view scheduled events, manage event details, and record when students arrive and leave each event.

Students can create an account, sign in, browse available events, and check in and check out for a specific event. Their attendance records can help them keep track of the events they have attended.

Administrators and organization officers can create new events, edit event information, remove events, and manage student records. Role-based access helps ensure that event and student management features are limited to authorized users, while students can use the attendance features available to them.

The system is built with PHP, MySQL, HTML, CSS, and JavaScript and is designed with a simple, responsive interface that can be used on desktop and mobile devices. It can run locally using XAMPP, making it suitable for school projects, demonstrations, and further development.

PROJECT OBJECTIVE

The main objective of this system is to simplify gymnasium event management, reduce manual attendance tracking, and provide an organized way to manage event information and student participation.

TECHNOLOGIES USED

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- XAMPP

This project is intended for educational use and may be customized to suit the needs of a school or student organization.
